# Мониторинг сети

Консольный монитор сети для Windows: пингует роутер, Cloudflare, Google, Яндекс и Discord, показывает задержку, потери и джиттер, а в конце сохраняет CSV-лог.

## Запуск

Двойной клик по `Мониторинг.cmd` или:

```powershell
powershell -ExecutionPolicy Bypass -File .\netmon.ps1
```

По умолчанию 30 раундов по 1 секунде. Можно изменить:

```powershell
.\netmon.ps1 -Rounds 120 -Timeout 1200
```

- `-Rounds` — количество раундов.
- `-Timeout` — таймаут одного пинга в миллисекундах.

Остановить досрочно: `Ctrl+C` — итоги всё равно посчитаются.

## Что показывает

- текущую задержку и график;
- минимум, среднее и максимум;
- процент потерь и джиттер;
- итоговую таблицу по каждой цели.

Логи складываются рядом со скриптом в `ping_ГГГГ-ММ-ДД_ЧЧ-ММ.csv`. В репозиторий они не попадают (см. `.gitignore`).

## Требования

Windows PowerShell 5.1+ и доступ в сеть. Ничего устанавливать не нужно.
